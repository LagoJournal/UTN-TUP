## Ejecutar

Abrir el proyecto en el IDE y ejecutar el `Main.java` de cada paquete (`interfaces` y `excepciones`).

Por consola, desde la raíz:

```
javac -d out src/interfaces/*.java src/excepciones/*.java
java -cp out interfaces.Main
java -cp out excepciones.Main
```

Para los ejercicios de archivos se puede usar `archivo.txt`.
